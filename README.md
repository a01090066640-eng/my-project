# 산업 데이터 관리 대시보드

산업 지표(매크로, AI/반도체, 원자재, 수출입, 인바운드 등)의 갱신 현황을 추적하고, 임계치를 넘은
지표를 하이라이트하며, 그 근거로 투자 아이디어를 정리해서 보여주는 대시보드입니다.

현재는 샘플(mock) 데이터로 구성되어 있으며, 실제 데이터 파이프라인(크롤러/수집 잡)과의 연동은
`src/data/mockData.ts`를 실제 데이터 소스로 교체하는 방식으로 이어서 진행할 수 있습니다.

## 구성

- 🔔 **지금 해야 할 것** — 지연되거나 조치가 필요한 지표 알림
- 📅 **최근 업데이트** — 주기(일간/주간/월간)별 최근 갱신 로그
- ⭐ **오늘의 주목할만한 지표** — 카테고리별 임계치 돌파 지표 (🔴 긴급 · 🟠 주의 · 🔵 참고)
- ⭐ **오늘의 투자아이디어** — 주목 지표를 근거로 한 종목별 체크리스트
- 🗓 **카테고리별 갱신 현황** — 전체 카테고리의 정상/지연 상태 그리드

라이트/다크 테마를 지원하며 선택한 테마는 브라우저에 저장됩니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint     # oxlint
```

## 스택

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
